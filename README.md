## 简介

YOMII 是 **JM Comic 的非官方第三方客户端**，基于 Kotlin + Jetpack Compose 开发，通过 Chaquopy 内嵌 Python `jmcomic` 库获取数据。

## 功能

- 首页推荐、分类浏览与搜索
- 漫画详情与章节列表
- 连续滚动阅读，图片预加载与本地缓存
- 漫画离线下载
- 账号登录、收藏同步
