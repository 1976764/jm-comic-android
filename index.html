项目简介

JM Comic 是一款基于 Android 原生开发的漫画阅读客户端， 采用 Jetpack Compose + Python 混合架构。 通过 Chaquopy 将 Python jmcomic 库嵌入 Android 原生应用， 实现漫画的搜索、浏览、阅读与下载功能。

前端使用 Jetpack Compose 构建 Material 3 风格的现代化 UI， 后端通过 Python 桥接层调用 jmcomic 库完成数据获取与图片处理。

Android Kotlin Python 3.13+ Jetpack Compose MVVM Chaquopy 17.0.0 Coil 2.7.0
