YOMII

一款基于 Android 原生开发的漫画阅读客户端，采用 Jetpack Compose + Python 混合架构。

Android Kotlin Python 3.13+ Jetpack Compose MVVM Chaquopy
下载 YOMII GitHub

核心功能

YOMII 通过 Chaquopy 将 Python jmcomic 库嵌入 Android 原生应用，实现漫画的搜索、浏览、阅读与下载。

首页 & 分类

两列网格无限滚动，按标签分类浏览，快速发现感兴趣的作品。

搜索

关键词实时搜索，支持按年份、月份排序，快速定位目标漫画。

详情 & 阅读器

封面、章节列表，连续滚动阅读，支持夜间模式与护眼模式。

用户系统

登录、Cookie 恢复、收藏管理，支持自定义书签与阅读进度同步。

下载管理

离线下载，支持章节缓存与批量下载，无网络也能随时阅读。

混合架构

Kotlin + Python 桥接，兼顾原生性能与 Python 生态的灵活性。
